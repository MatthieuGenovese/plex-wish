# Logos d'attribution

Les conditions de l'API TMDB imposent d'afficher leur logo et la mention
« This application uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB. »
(page À propos de l'application).

Déposer ici le logo officiel, **sans le modifier** (pas de recoloration, pas de recadrage) :

- `tmdb-logo.svg` : un des logos proposés sur https://www.themoviedb.org/about/logos-attribution
  (une version horizontale courte convient le mieux).

Tant que le fichier manque, la page À propos affiche « TMDB » en texte à la place du logo.
Le logo reste affiché en petit : il ne doit pas être plus visible que le nom de l'application.
